**Racing_Game**

This is a two player racing game done using the turtle module in python.

**************************************
**HOW TO USE**\
\
Download and open the .py file to run the game.
If python isn't installed, install it.
[Install python from this webstei](https://www.python.org/)
\
At present, there are no rules on how to play this game, if you hit the the cyan color in the middle, your car will reset.
\
Figure out your own rules with your partner and play!
